# 手势控制

## 功能说明

可选摄像头手势控制

- 手势鼠标与快捷操作
- 摄像头配置和状态显示
- 握拳语音输入

## 使用方式

在插件管理中添加并启用手势控制，运行 `/gesture install` 安装组件，然后使用 `/gesture start` 手动启动。`/gesture status` 查询状态，`/gesture stop` 关闭摄像头。

## 依赖与限制

需要手势组件和摄像头授权。握拳语音还需启用语音输入并安装离线语音组件。安装插件不会自动启动设备。
