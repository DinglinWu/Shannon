# 语音输入

## 功能说明

可选离线语音输入

- 按住说话、松开结束
- 本地识别并按光标位置插入文本

## 使用方式

在插件管理中添加并启用语音输入，再使用 `/voice install` 安装离线识别组件。在主搜索框内长按鼠标左键约650毫秒开始，松开或按 Esc 结束；识别文字不会自动发送。

## 依赖与限制

需要离线语音组件和麦克风授权。识别在本机 CPU 运行，不上传音频；安装插件不会自动启动麦克风。
