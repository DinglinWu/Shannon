# 闪念主题规范 v1

主题以文件夹为单位，包含一份 `theme.json` 与若干图片，**不支持脚本**。
配色、装饰图片、提示文字与唤起特效均在 `theme.json` 中定义，闪念按日期自动启用。

本文档面向主题作者，也可直接提供给 AI：将全文连同需求（如"制作一个中秋主题"）一并发送，即可生成可用的主题包。

---

## 1. 主题目录

| 来源 | 位置 | 说明 |
|---|---|---|
| 内置 | 项目目录 `public/themes/<id>/`，并在 `public/themes/index.json` 的 `themes` 数组中登记 | 随安装包发布，修改后需重新打包 |
| 自定义 | `%APPDATA%\com.brynn.ailauncher\themes\<id>\` | 放入后无需重启，最迟一分钟内生效；执行 `/theme` 时立即重新扫描 |
| 在线 | 仓库 `themes/<id>/`，同步至 `%APPDATA%\com.brynn.ailauncher\online-themes\<id>\` | 由发布者推送，闪念定期同步，无需更新版本，见第 8 节 |

- `<id>` 即文件夹名，仅可包含**小写字母、数字与连字符**，例如 `national-day`、`mid-autumn-2026`。
- 主题同名时，优先级为：自定义 > 在线 > 内置。在线主题可用于修正已发布的内置主题。

```
national-day/
├─ theme.json
├─ lantern.svg
└─ pattern.svg
```

## 2. theme.json 示例

```json
{
  "spec": 1,
  "id": "national-day",
  "name": "国庆",
  "author": "Shannon",
  "when": { "from": "10-01", "to": "10-07" },
  "priority": 10,
  "tokens": {
    "--accent": "#d7261e",
    "--bg": "#fffaf5",
    "--bg-grouped": "#fbf0e8",
    "--surface": "#fffdfb"
  },
  "slots": {
    "placeholder": "国庆快乐",
    "badge":   { "image": "lantern.svg", "height": 30, "label": "国庆快乐" },
    "pattern": { "image": "pattern.svg", "opacity": 0.06, "size": 120 }
  },
  "enter": {
    "effect": "fireworks",
    "scope": "screen",
    "frequency": "daily",
    "duration": 3400,
    "message": "闪念祝福祖国繁荣昌盛",
    "params": { "colors": ["#ffd23f", "#ff4b3e", "#ffb347"], "bursts": 7, "particles": 80 }
  }
}
```

## 3. 字段说明

除 `spec` 外，其余字段均为可选。无效字段将被忽略，不影响程序运行；
执行 `/theme 名称` 时会列出被忽略的字段，执行 `/theme` 时会列出加载失败的主题及原因。

### 顶层字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `spec` | 数字，**必填** | 固定为 `1` |
| `id` | 字符串 | 可省略；填写时须与文件夹名一致 |
| `name` | 字符串，不超过 24 字 | 显示名称，可用于 `/theme 名称` 切换 |
| `author` | 字符串 | 作者 |
| `when` | `{from, to}` | 生效日期，**包含起止两天**，见下文 |
| `priority` | -100 ~ 100，默认 0 | 同一天有多个主题生效时，数值大者优先；数值相同时依次为自定义、在线、内置主题 |

`when` 支持两种格式，`from` 与 `to` 须使用同一种：

- `"10-01"` ~ `"10-07"`：**每年**生效，支持跨年，例如 `"12-31"` ~ `"01-02"`
- `"2026-09-25"` ~ `"2026-09-27"`：仅当年生效。春节、中秋等农历节日每年日期不同，应使用此格式

未设置 `when` 的主题不会自动启用，仅可通过 `/theme 名称` 手动启用。

### tokens：配色

以 CSS 变量名为键、颜色值为值，覆盖默认外观。仅需填写要修改的变量。

| 变量 | 默认值 | 用途 |
|---|---|---|
| `--accent` | `#007aff` | 强调色：命令高亮、打开模式高亮、开关、链接、用户消息气泡 |
| `--accent-rgb` | `0, 122, 255` | 强调色的 RGB 分量。**仅设置十六进制 `--accent` 时将自动计算**，通常无需填写 |
| `--bg` | `#f6f6f8` | 窗口背景 |
| `--bg-grouped` | `#efeff3` | 侧栏与设置面板背景 |
| `--surface` | `#fff` | 浮层表面：回答卡片、设置按钮、复制按钮、移动手柄 |
| `--label` | `#1d1d1f` | 主要文字 |
| `--label-2` | `rgba(60, 60, 67, 0.62)` | 次要文字 |
| `--label-3` | `rgba(60, 60, 67, 0.34)` | 提示文字、次要图标 |
| `--fill` | `rgba(120, 120, 128, 0.12)` | 控件背景、行内代码、悬停状态 |
| `--fill-2` | `rgba(120, 120, 128, 0.2)` | 按下状态、强调悬停状态 |
| `--separator` | `rgba(60, 60, 67, 0.1)` | 分隔线 |
| `--red` / `--green` | `#ff3b30` / `#34c759` | 错误、成功 |
| `--r-window` | `12px` | 窗口圆角（`--r-md` / `--r-sm` / `--r-xs` / `--r-bubble` 同理） |

限制：

- 值中不得包含 `url(`、`;`、`{`、`}`、`<`、`>`、`\`，否则整条忽略
- 最多 40 条

建议：

- 节日主题通常只需调整 `--accent`、`--bg`、`--bg-grouped`、`--surface`，并为 `--fill` 加入同色调
- 文字颜色一般保持默认，以确保可读性
- 暂不建议制作深色主题：界面中仍有少量固定白色元素（开关圆钮、设置图标）

### slots：装饰位

| 装饰位 | 字段 | 说明 |
|---|---|---|
| `placeholder` | 字符串，不超过 40 字 | 输入框为空时显示的提示文字 |
| `badge` | `image` 必填；`height` 16~40，默认 28；`label` 图片的无障碍描述，默认取 `name` | 替代展开按钮的箭头显示，出现时带弹出动画；点击照常展开 / 收起历史对话，鼠标悬停时显示箭头；打开模式下随展开按钮一同隐藏 |
| `pattern` | `image` 必填；`opacity` 0.02~0.3，默认 0.08；`size` 平铺尺寸（px）24~400，默认 120 | 铺满窗口、位于文字下层的底纹 |

图片要求：

- 格式：`svg` / `png` / `jpg` / `webp` / `gif`，单张不超过 2 MB
- 文件名仅可包含字母、数字、`-`、`_`、`.`，须位于主题文件夹根目录
- `badge` 建议使用 SVG，高宽比 1:1 ~ 1:1.4；显示尺寸不超过 34 × 34 px，应减少细节、保持轮廓清晰
- `pattern` 应使用**单色、细线、留白充足**的平铺图，并通过 `opacity` 控制在 0.04~0.08，避免影响阅读
- SVG 中的 `<script>` 与外部图片引用均不会生效

### enter：唤起特效

每次唤起窗口时按 `frequency` 判断是否播放。系统开启"减少动画"时不播放。

| 字段 | 取值 | 说明 |
|---|---|---|
| `effect` | `"fireworks"` / `"particles"` | 特效名称，须为内置特效 |
| `scope` | `"window"`（默认）/ `"screen"` | 在窗口内播放，或全屏播放。全屏播放时临时创建透明、鼠标穿透的窗口，播放结束后销毁；创建失败时自动改为窗口内播放 |
| `frequency` | `"daily"`（默认）/ `"always"` / `"once"` | 每天首次唤起时播放 / 每次唤起时播放 / 仅播放一次 |
| `duration` | 500~8000，默认 2800 | 时长（毫秒） |
| `message` | 字符串，不超过 24 字 | 寄语，见下文 |
| `params` | 对象 | 特效参数，见下文 |

**message：寄语**

特效播放时，寄语在搜索框上方的透明展示层中以强调色（`--accent`）逐字浮现，
配合主题的徽标、底纹与粒子图片作为装饰，停留后整体淡出。输入框原有内容始终可见、可编辑。
寄语全部浮现后至少停留 2 秒，时长不足时自动延长；上方空间较小时自动精简装饰，无足够空间时不显示寄语，避免覆盖输入框。
期间按任意键或点击主窗口将提前淡出寄语，按键照常输入；主窗口隐藏时一并收起。
展示层不接收鼠标点击；即使 `scope` 为 `window`，寄语也使用独立透明层显示在框外。

- 仅显示纯文本，不支持换行与格式；建议 12 字以内，以免超出输入框宽度
- 与特效同频率播放（`frequency`）；执行 `/theme 名称` 预览时同样显示
- 首次进入一个节日主题时先展示寄语、装饰，再过渡到节日配色；同一节日期间保持配色，后续按 `frequency` 播放特效时不再重复切换主题。已启用的节日外观会在重启后直接恢复；年度重复的节日每年重新判定一次开场。

**fireworks：烟花**

全屏播放时自屏幕底部升空后绽放；窗口内播放时原地绽放。

| 参数 | 默认值 | 范围 | 说明 |
|---|---|---|---|
| `colors` | 金、橙红、橙、米白 | 最多 12 个 `#rrggbb` | 每朵烟花随机选取一个主色与一个副色 |
| `bursts` | 全屏 6 / 窗口内 3 | 1~12 | 烟花数量 |
| `particles` | 70 | 20~160 | 每朵烟花的火花数量 |
| `gravity` | 1 | 0~3 | 火花下落速度 |
| `size` | 1 | 0.3~3 | 绽放半径倍数 |

**particles：飘落 / 升起**

以小图或彩色圆点批量飘落或升起，适用于落叶、雪花、花瓣、红包雨、孔明灯等效果。

| 参数 | 默认值 | 范围 | 说明 |
|---|---|---|---|
| `images` | 无（使用彩色圆点） | 最多 8 个文件名 | 每个粒子随机选取一张，文件须位于主题文件夹中 |
| `colors` | 同上 | | 未提供图片时圆点的颜色 |
| `direction` | `"down"` | `"down"` / `"up"` | 飘落或升起（孔明灯使用 `up`） |
| `count` | 全屏 40 / 窗口内 14 | 1~120 | 粒子数量 |
| `speed` | `[60, 140]` | 10~800 | 移动速度区间（像素 / 秒） |
| `size` | `[14, 26]` | 4~96 | 粒子宽度区间（像素），窗口内播放时自动缩小 |
| `sway` | 18 | 0~80 | 左右摆动幅度 |
| `spin` | `true` | | 是否旋转 |

示例：中秋桂花雨

```json
"enter": {
  "effect": "particles",
  "scope": "screen",
  "duration": 4000,
  "params": { "images": ["osmanthus.svg"], "count": 50, "speed": [50, 110], "size": [10, 18], "sway": 24 }
}
```

如需上述参数无法组合出的新特效，须在程序 `src/fx.js` 的 `EFFECTS` 中新增，并在本节补充参数说明。

## 4. 启用规则

每次唤起窗口时重新判断（程序常驻运行，跨越零点后同样生效），依据为配置文件 `config.toml` 中 `[theme]` 的 `mode`（可通过 `/theme` 命令或 `/config` 修改）：

1. `mode` 为主题 ID（通过 `/theme 名称` 指定）：始终使用该主题，不考虑日期
2. `mode = "off"`（通过 `/theme off` 关闭）：使用默认外观
3. `mode = "auto"`：在当日生效的主题中选择 `priority` 最大者；数值相同时依次为自定义、在线、内置主题；无生效主题时使用默认外观

## 5. 命令

| 命令 | 说明 |
|---|---|
| `/theme` | 列出全部主题、当前模式，以及加载失败的主题和原因 |
| `/theme 名称或 ID` | 切换至该主题并**立即播放一次唤起特效**以供预览，此后持续生效 |
| `/theme auto` | 恢复按日期自动切换 |
| `/theme off` | 关闭主题 |
| `/theme sync` | 立即同步在线主题，并列出在线主题及未能同步的主题 |

## 6. 制作流程

1. 在 `%APPDATA%\com.brynn.ailauncher\themes\` 中新建文件夹，例如 `mid-autumn-2026`
2. 编写 `theme.json`，并将图片放入同一文件夹
3. 唤起闪念，输入 `/theme mid-autumn-2026` 预览
4. 确认无误后输入 `/theme auto`，主题将在生效日期自动启用
5. 发布给所有用户：将文件夹移至项目的 `themes/`，按第 8 节生成清单并推送（推荐）；
   或移至 `public/themes/` 并在 `public/themes/index.json` 中登记，随下一个安装包发布

## 7. 安全限制（由程序强制执行）

为支持后续远程推送，主题包**仅允许包含数据**：

- 程序不会执行主题中的任何代码。图片仅通过 `<img>` 或 CSS 背景显示，两种方式均不会运行 SVG 中的脚本
- 配色值会过滤 `url(` 等写法，主题无法通过配色访问外部资源
- 自定义主题与在线主题的文件夹名与文件名均经过校验，无法读取主题目录以外的文件
- 在线主题须通过签名与完整性校验，见第 8 节
- 特效参数均限制在上表所列范围内，异常取值不会影响程序稳定性

## 8. 在线主题

在线主题存放在公开仓库的 `themes/` 目录中，推送后已安装的闪念自动同步，无需发布新版本。

```
themes/
├─ index.json          主题清单（由 scripts/themes.py 生成，勿手动编辑）
├─ index.json.sig      清单签名
└─ mid-autumn-2026/
   ├─ theme.json
   └─ moon.svg
```

### 发布

1. 将主题文件夹放入项目根目录的 `themes/`，格式与自定义主题相同，建议先按第 6 节在本机预览
2. 运行 `scripts/themes.py`，输入私钥密码。脚本将校验每个主题，生成清单并签名
3. 提交并推送 `themes/` 目录

下架主题：从 `themes/` 中删除该文件夹，重新执行第 2、3 步，已同步的闪念将在下次同步时删除该主题。

### 同步规则

- 启动 20 秒后同步一次，此后按配置文件 `[update] check_interval_hours` 的间隔同步（默认 6 小时）；`/theme sync` 立即同步
- 仅下载缺失或内容有变化的文件；主题提前下载至本地，生效当日无需联网
- 同步到新内容后立即重新判断当前主题，无需重新唤起窗口
- 配置文件 `[theme] online = false` 关闭同步；已同步的主题保留在本地，仍按日期启用

### 校验

- 清单使用发布安装包的同一把私钥签名，闪念使用内置公钥验签；验签未通过时忽略整份清单
- 清单记录每个文件的大小与 SHA-256，文件下载后逐一核对，一个主题的全部文件通过后才替换旧版本
- 清单的生成时间早于本地已同步的版本时拒绝，防止旧清单被重放
- 在线主题与自定义主题执行相同的内容校验（第 7 节），仅允许 `theme.json` 与图片，不支持子文件夹
- 上限：32 个主题；每个主题 16 个文件、合计 8 MB

`.gitattributes` 已将 `themes/` 设为按原样提交。请勿删除该设置：Git 在 Windows 上默认转换换行符，转换后的文件将无法通过校验。
